TASK 05 — PRECISION / RECALL EVALUATION

Objective
--------
Compare the two RAG chunking strategies at the document level and select the
better strategy for subsequent tasks.

Strategies evaluated
--------------------
1. Fixed-size chunking
2. Sentence-based chunking

Evaluation method
-----------------
The same five in-scope queries were evaluated separately against both Chroma
collections.

For each query:
- Retrieve the top results.
- Map retrieved chunks back to their parent document IDs.
- Deduplicate parent document IDs.
- Compare the retrieved document IDs with the expected document IDs.
- Calculate document-level precision and recall.

Metrics
-------
Precision = true positives / retrieved relevant-document candidates

Recall = true positives / expected relevant documents

Test queries
------------
1. What is the return window for beauty products?
   Expected: return_window

2. How long does a COD refund take after approval?
   Expected: cod_refund_timelines

3. How long does delivery usually take after order confirmation?
   Expected: delivery_sla

4. What are the requirements for a reverse pickup?
   Expected: reverse_pickup

5. What should I do if my order arrives damaged?
   Expected: damaged_item_claims

Arithmetic check
----------------
Fixed-size mean precision:
(0.3333333333333333 + 0.25 + 0.25 + 0.3333333333333333 + 0.25) / 5
= 0.2833333333333333

Sentence mean precision:
(0.5 + 0.5 + 0.3333333333333333 + 0.5 + 0.2) / 5
= 0.4066666666666666

Both strategies have mean recall of 1.0 because the expected parent document
was retrieved for all five queries.

Decision
--------
Sentence-based chunking is selected for subsequent tasks.

Reason:
- Sentence strategy has higher mean document-level precision:
  0.4066666666666666 vs 0.2833333333333333.
- Both strategies have perfect mean recall of 1.0.
- Therefore sentence chunking provides better retrieval precision without
  sacrificing coverage of the expected documents in this evaluation.

Threshold carry-forward
-----------------------
Task 4 calibrated similarity thresholds separately for the two strategies.

Fixed-size calibrated threshold: 0.5056
Sentence calibrated threshold:   0.4844

Because sentence-based chunking is selected, the sentence strategy's
calibrated threshold of 0.4844 is the threshold to carry forward into later
tasks.

The DEFAULT_SIMILARITY_THRESHOLD value in generation.py does not need to be
manually changed solely because of this experiment. The calibrated value is
an experimental result associated with the selected strategy and should be
provided when the selected strategy is used later.

Conclusion
----------
Task 5 establishes the preferred retrieval configuration for the next stages:

    Chunking strategy: sentence
    Calibrated threshold: 0.4844

The fixed-size strategy remains documented as the comparison baseline.
